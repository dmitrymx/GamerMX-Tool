# GamerMX Tool

Нативный Windows-компаньон для геймеров и разработчиков, которые подолгу сидят за компьютером. Приложение напоминает о разминке, воде и отдыхе для глаз, не мешая игре или работе.

## Возможности

- точный таймер с часами, минутами и секундами;
- плавное убывающее кольцо таймера с экономным векторным рендерингом;
- готовые интервалы для глаз, разминки, воды и прогулки;
- компактный always-on-top оверлей для второго монитора;
- четыре размера оверлея: компактный, средний, большой HUD и полноэкранный;
- масштаб сцены от 70% до 180%;
- шесть экономных живых анимаций: «Аврора», «Орбиты», «Радар», «Импульс», «Звёздная пыль» и «Спокойный»;
- девять вариантов анимации самого таймера: Neon Arc, Segmented Halo, Dual Orbit, Reactor, Chrono Dots, Sweep, Pulse Core, Hex Core и Minimal;
- прозрачность всего приложения от 25% до 100%;
- режим пропуска кликов сквозь окно;
- глобальная клавиша `Ctrl + Shift + G` для возврата управления;
- локальные заметки без аккаунта и облачной синхронизации;
- статистика пауз, история текущего дня и серия дней;
- 10 оригинальных встроенных мелодий с предпрослушиванием, без внешних аудиофайлов и лицензионных ограничений;
- автозапуск вместе с Windows;
- локальное хранение настроек в `%LocalAppData%\GamerMX Tool`.

## Запуск

Готовый автономный файл находится в каталоге `dist` после публикации:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -o dist
```

Для сборки нужен .NET 9 SDK. Готовый EXE не требует установленного .NET.

## Управление оверлеем

Нажмите кнопку «Быстрый оверлей» или сочетание `Ctrl + Shift + G`. Режим пропуска кликов применяется только к оверлею; основное окно всегда остаётся интерактивным. Эта же комбинация гарантированно возвращает клики и выходит из оверлея.

## Совместимость с античитами

GamerMX Tool работает как обычное отдельное окно Windows:

- не внедряет DLL и код в игру;
- не читает и не изменяет память игрового процесса;
- не перехватывает DirectX/Vulkan;
- не изменяет файлы игры;
- не автоматизирует стрельбу, прицеливание или другой игровой ввод;
- глобальная клавиша регистрируется штатным `RegisterHotKey`, без keyboard hook.

Это архитектура класса обычных desktop-оверлеев, а не чита или тренера. Однако RICOCHET постоянно обновляется, поэтому абсолютную гарантию совместимости может дать только Activision. При изменении политики сверяйтесь с [Call of Duty Security and Enforcement Policy](https://support.activision.com/articles/call-of-duty-security-and-enforcement-policy).

> GamerMX Tool помогает соблюдать режим, но не является медицинским приложением. При боли, повышенном давлении или стойком дискомфорте обратитесь к врачу.
